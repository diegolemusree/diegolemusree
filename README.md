### How I work with Claude Code

- **Specs first.** Every project has a `CLAUDE.md` with the goal, rules, architecture and decisions, and I keep it current as the project changes.
- **Small, tested steps.** I build one phase at a time and test it before moving on, with a commit at the end of each phase.
- **Connected tools.** I use MCP servers (n8n, Google Sheets) so Claude Code can inspect and build workflows directly.
- **Ship it.** I handle Git/GitHub and deploy to Render, Vercel or GoHighLevel.
